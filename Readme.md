# 🤟 ASL Alphabet Recognition System

Real-time American Sign Language (ASL) alphabet recognition using hand-landmark
detection and a trained deep learning model. Sign letters in front of your
webcam and watch them translate into text live — with text-to-speech,
sentence history, and a polished web interface.

---

## Features

- **Real-time hand tracking** using MediaPipe Hands (up to 2 hands)
- **Letter classification** via a trained TensorFlow/Keras model
- **Stable prediction smoothing** — a rolling majority-vote buffer prevents
  flickery, one-frame misfires from polluting the output
- **Special signs supported**: `space` (insert a space) and `del` (delete
  last character)
- **Text-to-speech** — hear your sentence spoken aloud
- **Save to file** — sentences are logged with timestamps to
  `downloads/translation.txt`
- **Session history panel** — see every sentence you've saved, in-app
- **Streamlit web interface** with an aurora-themed UI, live confidence
  meter, and a dedicated sentence panel next to the camera feed

## How It Works

1. **Landmark extraction** — MediaPipe Hands detects up to 2 hands per frame
   and extracts 21 landmarks × 3 coordinates (x, y, z) per hand, giving a
   126-value feature vector (zero-padded if fewer than 2 hands are visible).
   These are **raw, unscaled** coordinates, matching how
   `dataset/landmarks.csv` was generated during training.
2. **Prediction** — the feature vector is passed to the trained Keras model,
   which outputs a probability distribution over the label set in
   `labels.txt`. Predictions below `CONFIDENCE_THRESHOLD` (default `0.70`)
   or matching an ignored label (`"nothing"`) are discarded.
3. **Stability smoothing** — predictions are collected into a rolling buffer
   (`WINDOW_SIZE = 6` frames). A label is only "committed" to the sentence
   once it holds a majority (`STABILITY_RATIO = 0.6`) within that buffer,
   which filters out noisy, transient misclassifications.
4. **Sentence building** — committed labels are appended to the sentence,
   with `space` and `del` handled as special actions rather than literal
   characters.

## Requirements

- Python 3.9–3.11 recommended (TensorFlow/MediaPipe compatibility)
- A working webcam

Install dependencies:

```bash
pip install streamlit opencv-python mediapipe tensorflow pyttsx3
```

---

## Running the App

```bash
streamlit run app.py
```

This opens the app in your browser (default: `http://localhost:8501`).

1. Click **▶ Start Camera** in the sidebar to begin live translation.
2. Sign letters in view of your webcam — the sentence builds automatically
   as stable predictions are detected.
3. Use the sidebar **Actions**:
   - **Clear** — reset the current sentence
   - **Delete** — remove the last character
   - **🔊 Speak** — read the current sentence aloud
   - **💾 Save** — append the sentence (with timestamp) to
     `downloads/translation.txt` and the in-app History panel
4. Click **■ Stop Camera** to release the webcam.

## Configuration

Tunable constants live at the top of `backend.py`:

| Constant               | Default | Description                                              |
|-------------------------|---------|------------------------------------------------------------|
| `CONFIDENCE_THRESHOLD`  | `0.70`  | Minimum model confidence to accept a prediction            |
| `IGNORED_LABELS`        | `{"nothing"}` | Labels that are never added to the sentence           |
| `WINDOW_SIZE`           | `6`     | Number of frames in the smoothing buffer                   |
| `STABILITY_RATIO`       | `0.6`   | Fraction of the buffer that must agree to commit a label    |
| `MODEL_PATH`            | `models/sign_model.keras` | Path to the trained model                |
| `LABELS_PATH`           | `models/labels.txt` | Path to the label list                          |
| `SAVE_PATH`             | `downloads/translation.txt` | Where saved sentences are logged        |

## Dataset Inspection

`inspect_landmarks.py` is a standalone script (not connected to the app) for
quickly sanity-checking `dataset/landmarks.csv`:

```bash
python inspect_landmarks.py
```

Prints the dataset shape, first 10 column names, the first row's feature
values, and overall min/max/mean across all feature columns.

## Known Limitations

- Streamlit's live-camera pattern (a `while` loop gated by a button) has
  more latency than a raw OpenCV window; sidebar interactions can feel
  slightly delayed while the camera is running.
- `pyttsx3.runAndWait()` blocks the UI briefly while speaking — this is
  expected behavior, not a bug.
- Recognition accuracy depends entirely on the quality and coverage of the
  data the model was trained on — poor lighting, unusual hand angles, or
  signs underrepresented in training data will reduce reliability.
